📂 অধ্যায়: ০১
📌 টপিক: জাভাস্ক্রিপ্ট কী, কেন এবং কীভাবে কাজ করে?
========================================================================

■ What? (JavaScript কী?)
------------------------------------------------------------------------
JavaScript হলো ওয়েবসাইটের "মস্তিষ্ক" বা "প্রাণ"। 
একটি বাড়ি বা ওয়েবসাইটের উদাহরণ:
* HTML: বাড়ির দেয়াল বা ইটের কাঠামো (লেখা বা ছবি)।
* CSS: বাড়ির রং এবং ডিজাইন (সৌন্দর্য)।
* JavaScript: বাড়ির ইলেকট্রিক ওয়ারিং, সুইচ বা ফ্যান (কাজ করার ক্ষমতা)।

■ Why? (কেন শিখব?)
------------------------------------------------------------------------
১. ওয়েবসাইটকে জীবন্ত করতে (ক্লিক করলে পপ-আপ আসা, মেনু খোলা ইত্যাদি)।
২. পৃথিবীর ৯৮% এর বেশি ওয়েবসাইট জাভাস্ক্রিপ্ট ব্যবহার করে।
৩. এটি দিয়ে ফ্রন্টএন্ড (React), ব্যাকএন্ড (Node.js) এবং মোবাইল অ্যাপও বানানো যায়।

■ How? (কীভাবে কাজ করে?)
------------------------------------------------------------------------
ব্রাউজারের (যেমন: Chrome) ভেতরে "JavaScript Engine" নামের একটি সফটওয়্যার 
বা রোবট থাকে। আমরা যে কোড লিখি, এই ইঞ্জিনটি তা পড়ে ব্রাউজারে আউটপুট দেখায়।

📂 অধ্যায়: ০২
📌 টপিক: ভেরিয়েবল বা চলক (Variables - var, let, const)
========================================================================

■ What? (ভেরিয়েবল কী?)
------------------------------------------------------------------------
ভেরিয়েবল হলো কম্পিউটারের মেমরিতে তথ্য জমা রাখার একটি "বাক্স" বা "কন্টেইনার"।

■ Why? (কেন লাগবে?)
------------------------------------------------------------------------
একই তথ্য (যেমন: ইউজারনেম "Tabib") যদি ওয়েবসাইটের ১০টি জায়গায় দেখাতে হয়, 
তবে সরাসরি ১০ বার না লিখে ১টি বাক্সে রেখে দিলে সুবিধা। পরে নাম বদলালে শুধু 
বাক্সের ভেতরের নামটা ১ বার বদলে দিলেই সব জায়গায় বদলে যায়।

■ How? (কীভাবে লিখব এবং ৩টির আসল তফাত কী?)
------------------------------------------------------------------------
১. var (পুরোনো আমলের বাক্স - নিষিদ্ধ ❌):
   একই নামে বারবার বাক্স খোলা যায়। কোডে বাগ বা ভুল তৈরি করে।
   var tabibName = "Tabib";

২. let (আধুনিক বাক্স - পরিবর্তনশীল ✅):
   যার ভেতরের তথ্য ভবিষ্যতে পরিবর্তন হতে পারে, সেখানে এটি বসে।
   let tabibAge = 21;
   tabibAge = 22; // মান পরিবর্তন সম্ভব।

৩. const (তালা মারা লোহার বাক্স - অপরিবর্তনশীল 🔒):
   যে তথ্য কখনো বদলাবে না, তার সুরক্ষার জন্য এটি ব্যবহৃত হয়।
   const tabibName = "Tahsin Al Tabib"; 
   // tabibName = "Arif"; -> এটি করতে গেলে কম্পিউটার Error দেবে।

■ ভেরিয়েবলের নাম রাখার নিয়ম (Naming Rules):
------------------------------------------------------------------------
১. স্পেস দেওয়া যাবে না (যেমন: let tabib age = 21; ❌)।
২. ক্যামেল কেস (camelCase) লিখতে হবে (যেমন: let tabibAge = 21; ✅)।
৩. সংখ্যা দিয়ে শুরু করা যাবে না (যেমন: let 1stName = "Tabib"; ❌)।
৪. বিশেষ চিহ্ন (@, #, -) ব্যবহার করা যাবে না। শুধু ($) এবং (_) চলবে।

📂 অধ্যায়: ০৩
📌 টপিক: ডাটা টাইপ (Data Types - সম্পূর্ণ মানচিত্র)
========================================================================

জাভাস্ক্রিপ্টে ডাটা টাইপ প্রধানত ২ ভাগে বিভক্ত এবং মোট ৮ ধরনের রয়েছে।

                  ┌──────────────────────────────┐
                  │   JavaScript Data Types      │
                  └──────────────┬───────────────┘
                                 │
         ┌───────────────────────┴───────────────────────┐
         ▼                                               ▼
 ┌───────────────┐                               ┌───────────────┐
 │   Primitive   │                               │ Non-Primitive │
 │   (মৌলিক)     │                               │  (রেফারেন্স)  │
 └───────┬───────┘                               └───────┬───────┘
         │                                               │
         ├── 1. String ("Tabib")                         └── 8. Object
         ├── 2. Number (21, 3.95)                             (অ্যারে ও ফাংশনসহ)
         ├── 3. Boolean (true/false)
         ├── 4. Undefined (খালি)
         ├── 5. Null (ইচ্ছে করে খালি)
         ├── 6. Symbol (ইউনিক আইডি)
         └── 7. BigInt (বিশাল বড় সংখ্যা)

🌟 ভাগ ১: Primitive (মৌলিক ডাটা টাইপ)
------------------------------------------------------------------------
একক মান (Single Value) জমা রাখে। কম্পিউটারের মেমরিতে সরাসরি মান বসে।

১. String: কোটেশনের ভেতরের টেক্সট। -> const name = "Tabib";
২. Number: সংখ্যা (পূর্ণসংখ্যা বা দশমিক)। -> let age = 21;
৩. Boolean: লজিক্যাল সিদ্ধান্ত। -> const isCoder = true;
৪. Undefined: ভেরিয়েবল ঘোষণা করা হয়েছে কিন্তু মান দেওয়া হয়নি। -> let car;
৫. Null: ইচ্ছাকৃতভাবে ফাঁকা বা শূন্য মান সেট করা। -> let balance = null;
৬. Symbol: একদম অনন্য বা ইউনিক আইডি তৈরিতে লাগে। -> const id = Symbol();
৭. BigInt: সাধারণ Number সীমার বাইরের বিশাল বড় সংখ্যা। -> let huge = 100n;

🌟 ভাগ ২: Non-Primitive (রেফারেন্স ডাটা টাইপ)
------------------------------------------------------------------------
এক সাথে অনেকগুলো ডাটার কালেকশন জমা রাখে। মেমরিতে সরাসরি মান না রেখে, 
মানের ঠিকানা বা রেফারেন্স (Address) ধরে রাখে।

৮. Object: দ্বিতীয় বন্ধনী { } দিয়ে লেখা হয় এবং key: value আকারে ডাটা থাকে।
   const tabibDetails = {
       name: "Tahsin Al Tabib",
       age: 21,
       isCoder: true,
       skills: ["Javascript", "React Js", "Node Js"] // Array (স্পেশাল অবজেক্ট)
   };

💡 ইন্টারভিউ হ্যাক: typeof null চেক করলে আউটপুট "object" দেখায়। এটি 
   জাভাস্ক্রিপ্টের একটি ঐতিহাসিক ভুল বা Bug।

📂 অধ্যায়: ০৪
📌 টপিক: অপারেটরস (Comparison Operators - == বনাম ===)
========================================================================

■ == (Double Equal - Loose Equality):
------------------------------------------------------------------------
এটি দুটি জিনিসের শুধু মান সমান কিনা দেখে, কিন্তু ডাটা টাইপ চেক করে না।
5 == "5" -> আউটপুট: true (কারণ দুইটার মানই পাঁচ)

■ === (Triple Equal - Strict Equality):
------------------------------------------------------------------------
এটি দুটি জিনিসের মান এবং ডাটা টাইপ—দুটিই কঠোরভাবে পরীক্ষা করে।
5 === "5" -> আউটপুট: false (কারণ একটি Number এবং অন্যটি String)

👉 গোল্ডেন রুল: React ও Node-এ আমরা সবসময় '===' ব্যবহার করব।

■ লজিক্যাল অপারেটর:
------------------------------------------------------------------------
* && (AND): সবগুলো শর্ত সত্য হতে হবে। (শর্ত ১ && শর্ত ২)
* || (OR): যেকোনো একটি শর্ত সত্য হলেই চলবে। (শর্ত ১ || শর্ত ২)

📌 টপিক: কন্ডিশনাল এবং টার্নারি অপারেটর (If-Else & Ternary)
========================================================================

■ If-Else স্ট্রাকচার:
------------------------------------------------------------------------
if (tabibAge >= 18) {
    console.log("লাইসেন্স পাবে");
} else {
    console.log("ছোট আছো");
}

■ Ternary Operator (এক লাইনে If-Else লেখার ম্যাজিক):
------------------------------------------------------------------------
React-এর JSX-এর ভেতরে সাধারণ If-Else চলে না, সেখানে এটি ১০০% ব্যবহার হয়।

সিনট্যাক্স: শর্ত  ? সত্য_হলে_যা_হবে : মিথ্যা_হলে_যা_হবে;

💻 উদাহরণ:
let status = (tabibAge >= 18) ? "Adult" : "Child";

========================================================================
📂 অধ্যায়: Conditionals (পার্ট - ২)
📌 টপিক: Ternary Operator (টার্নারি অপারেটর)
========================================================================

■ What? (টার্নারি অপারেটর কী?)
------------------------------------------------------------------------
Ternary Operator হলো সাধারণ If-Else কন্ডিশনকে মাত্র এক লাইনে লেখার একটি 
শর্টকাট বা মডার্ন উপায়। 

■ Why? (আমরা কেন এটি ব্যবহার করব?)
------------------------------------------------------------------------
১. কোডের সাইজ কমায়: ৪-৫ লাইনের If-Else কোডকে এটি মাত্র ১ লাইনে নিয়ে আসে।
২. React-এর জন্য অপরিহার্য: React-এর JSX বা স্ক্রিনের ভেতরের কন্ডিশনাল 
   রেন্ডারিং করার জন্য সাধারণ If-Else ব্যবহার করা যায় না। সেখানে ১০০% সময় 
   এই Ternary Operator ব্যবহার করতে হয়।

■ How? (এটি কীভাবে কাজ করে এবং লেখার নিয়ম কী?)
------------------------------------------------------------------------
এর ভেতরের মেকানিজমটি মূলত ৩টি জিনিস নিয়ে কাজ করে: `শর্ত`, `?` এবং `:`

সিনট্যাক্স (Syntax):
শর্ত ? (শর্ত সত্য হলে যা হবে) : (শর্ত মিথ্যা হলে যা হবে);

------------------------------------------------------------------------
💻 উদাহরণ ১: সাধারণ If-Else বনাম মডার্ন Ternary Operator
------------------------------------------------------------------------

👉 পুরোনো স্টাইল (Traditional If-Else):
let tabibAge = 21;
let status;

if (tabibAge >= 18) {
    status = "Adult";
} else {
    status = "Child";
}
console.log(status); // আউটপুট: Adult


👉 মডার্ন স্টাইল (Ternary Operator):
let tabibAge = 21;

let status = (tabibAge >= 18) ? "Adult" : "Child";
console.log(status); // আউটপুট: Adult

[ব্যাখ্যা: কম্পিউটার প্রথমে 'tabibAge >= 18' চেক করল। যেহেতু এটা সত্য, 
তাই সে '?' এর ঠিক পরের "Adult" লেখাটি নিয়ে 'status' বাক্সে ঢুকিয়ে দিল।]

------------------------------------------------------------------------
💻 উদাহরণ ২: React-এ বাস্তব ব্যবহার (Real-life Use Case)
------------------------------------------------------------------------
ধরে নাও, তাবিব লগইন করে থাকলে স্ক্রিনে "Log Out" বাটন দেখাবে, আর লগইন 
না থাকলে "Log In" বাটন দেখাবে।

const isTabibLoggedIn = true;

const buttonText = isTabibLoggedIn ? "Log Out" : "Log In";
console.log(buttonText); // আউটপুট: Log Out

📂 অধ্যায়: ০৬
📌 টপিক: Functions (ফাংশন - জাভাস্ক্রিপ্টের প্রাণ)
========================================================================

■ What? (ফাংশন কী?)
------------------------------------------------------------------------
ফাংশন হলো একটি নির্দিষ্ট "কাজের ব্লক" বা "মেশিন"। তুমি এই মেশিনের ভেতর 
কিছু কাঁচামাল (Data) দেবে, মেশিন তার ভেতর কাজ করবে এবং তোমাকে একটা ফলাফল 
(Output) বের করে দেবে।

■ Why? (কেন লাগবে? React-এর বাস্তব উদাহরণ)
------------------------------------------------------------------------
১. কোড বারবার না লেখা (Reusability): ধরো, তোমার ১০ জন ইউজারের জন্মসাল 
   থেকে বয়স বের করতে হবে। তুমি ১০ বার এক হিসাব না লিখে, ১টা মেশিন (ফাংশন) 
   বানিয়ে রাখবে। যখনই দরকার, সেই মেশিনে জন্মসাল দিলেই বয়স বের হয়ে আসবে।
২. React-এর মূল ভিত্তি: React-এ আমরা যে "Component" বানাই, সেগুলো আসলে 
   একেকটা জাভাস্ক্রিপ্ট ফাংশন! (যেমন: function App() { ... })

■ How? (কীভাবে ফাংশন তৈরি করতে হয় এবং ব্যবহার করতে হয়?)
------------------------------------------------------------------------
একটি সাধারণ ফাংশন তৈরি করতে ৩টি জিনিস লাগে:
১. function কিওয়ার্ড
২. ফাংশনের একটা নাম
৩. প্রথম বন্ধনী () এবং দ্বিতীয় বন্ধনী {}

💻 উদাহরণ ১: একদম সহজ ফাংশন (কাঁচামাল ছাড়া)
------------------------------------------------------------------------
// ১. ফাংশন তৈরি করা (Declaration)
function sayWelcome() {
    console.log("স্বাগতম তাবিব! কোডিংয়ের দুনিয়ায়।");
}

// ২. ফাংশনটি চালানো বা কল করা (Calling/Invoking)
sayWelcome(); // আউটপুট: স্বাগতম তাবিব! কোডিংয়ের দুনিয়ায়।

------------------------------------------------------------------------
💻 উদাহরণ ২: প্যারামিটার এবং আর্গুমেন্ট (কাঁচামালসহ ফাংশন)
------------------------------------------------------------------------
মেশিনের ভেতরের ইনপুট নেওয়ার জায়গাকে বলে Parameter, আর কল করার সময় যে আসল 
মানটা আমরা পাঠাই, তাকে বলে Argument।

// এখানে 'name' হলো Parameter (একটি খালি চলক বা ভেরিয়েবল)
function greetUser(name) {
    console.log("হ্যালো " + name + ", কেমন আছো?");
}

// কল করার সময় আমরা আসল মান "Tabib" পাঠালাম, একে বলে Argument
greetUser("Tabib"); // আউটপুট: হ্যালো Tabib, কেমন আছো?
greetUser("Arif");  // আউটপুট: হ্যালো Arif, কেমন আছো?

------------------------------------------------------------------------
💻 উদাহরণ ৩: Return কিওয়ার্ড (ফলাফল বের করে আনা)
------------------------------------------------------------------------
ফাংশনের ভেতর কাজ শেষ করে ফলাফলটি বাইরে পাঠানোর জন্য `return` ব্যবহার করা হয়। 
মনে রাখবে, `return` লাইনের পর ফাংশনের ভেতর আর কোনো কোড কাজ করে না।

function addNumbers(num1, num2) {
    let result = num1 + num2;
    return result; // ফলাফল বাইরে পাঠিয়ে দিল
}

// ফাংশন থেকে আসা ফলাফলটি একটি ভেরিয়েবলে জমা রাখলাম
let totalSum = addNumbers(10, 20);
console.log(totalSum); // আউটপুট: 30

📂 অধ্যায়: ০৬ (পার্ট - ২)
📌 টপিক: Anatomy of a Function (ফাংশনের ব্যবচ্ছেদ)
========================================================================

নিচের কোডটির প্রতিটি অংশকে যা বলা হয়:

  function   sayWelcome  ( )  { ... }
    │            │        │     │
    │            │        │     └── 4. Function Body (ফাংশনের পেট বা কাজ)
    │            │        └── 3. Parameters Space (প্যারামিটারের জায়গা)
    │            └── 2. Function Name (ফাংশনের নাম)
    └── 1. Function Keyword (ফাংশন কিওয়ার্ড)


■ ১. Function Keyword (`function`)
------------------------------------------------------------------------
* What? এটি জাভাস্ক্রিপ্টের একটি সংরক্ষিত শব্দ বা Keyword।
* Why? এটি দেখে জাভাস্ক্রিপ্ট ইঞ্জিন বা ব্রাউজার বুঝতে পারে যে, তুমি মেমরিতে 
       একটি নতুন কাজের মেশিন তৈরি করতে যাচ্ছ।

■ ২. Function Name (`sayWelcome`)
------------------------------------------------------------------------
* What? এটি হলো তোমার তৈরি করা মেশিনের নিজস্ব নাম।
* Why? কোডের অন্য যেকোনো জায়গা থেকে এই মেশিনটিকে চেনার এবং ডাকার জন্য এই নাম 
       ব্যবহার করা হয়। নাম লেখার সময়ও ভেরিয়েবলের মতো camelCase নিয়ম মানতে হয়।

■ ৩. Parameter / Parentheses `()`
------------------------------------------------------------------------
* What? ফাংশনের নামের পাশে যে প্রথম বন্ধনী বা ফার্স্ট ব্র্যাকেট থাকে।
* Why? এটি হলো মেশিনের "ইনপুট নেওয়ার গেট বা ফানেল"। মেশিনের ভেতর কাজ করানোর 
       জন্য বাইরে থেকে যে কাঁচামাল বা ডাটা পাঠানো হবে, তা এই ব্র্যাকেটের ভেতর 
       ভেরিয়েবল (Parameter) হিসেবে রিসিভ করা হয়। (তোমার এই ফাংশনটি আপাতত 
       খালি, অর্থাৎ এটি কোনো ইনপুট ছাড়াই কাজ করতে পারে)।

■ ৪. Function Body `{ ... }`
------------------------------------------------------------------------
* What? দ্বিতীয় বন্ধনী বা কার্লি ব্রেসেস-এর ভেতরের পুরো অংশকে বলে Function Body।
* Why? এটি হলো মেশিনের আসল কারখানা বা পেট। মেশিনটি ঠিক কী কাজ করবে (যেমন তোমার 
       কোডে console.log করা), তার আসল লজিক বা কোড এই ব্র্যাকেটের ভেতরেই লেখা হয়।

■ ৫. Function Call / Invoke (`sayWelcome();`)
------------------------------------------------------------------------
* What? ফাংশন বডির বাইরে এসে নামের শেষে ফার্স্ট ব্র্যাকেট `()` দিয়ে সেমিকোলন দেওয়া।
* Why? শুধু ফাংশন বানিয়ে রাখলে তা নিজে নিজে কোনো কাজ করে না। এই লাইনের মাধ্যমে 
       তুমি মেশিনটিকে অর্ডার করলে—"মেশিন চালু হও এবং তোমার ভেতরের কাজটা করো!" 
       একে টেকনিক্যাল ভাষায় বলে Function Call বা Function Invocation।

📂 অধ্যায়: ০৬ (পার্ট - ৩)
📌 টপিক: String Concatenation vs Template Literals (লেখা জোড়া লাগানো)
========================================================================

■ ১. পুরোনো স্টাইল (String Concatenation - প্লাস চিহ্ন দিয়ে):
------------------------------------------------------------------------
* What? লেখার সাথে ভেরিয়েবল জোড়া লাগাতে প্লাস (+) চিহ্ন ব্যবহার করা হয়।
* How? 
  let name = "Tabib";
  console.log("হ্যালো " + name + ", কেমন আছো?"); 
  // আউটপুট: হ্যালো Tabib, কেমন আছো?

■ ২. মডার্ন স্টাইল (Template Literals - React-এ ১০০% ব্যবহৃত হয় ✅):
------------------------------------------------------------------------
* What? প্লাস (+) চিহ্ন বা ডাবল কোটেশন ("") ছাড়া, কিবোর্ডের Esc বাটনের নিচে 
       থাকা ব্যাকটিক (``) চিহ্ন এবং `${ভেরিয়েবল}` ব্যবহার করে এক লাইনে লেখা।
* Why? এটি দেখতে সুন্দর, লেখার মাঝে প্লাস বা স্পেস দেওয়ার কোনো ঝামেলা নেই।

💻 উদাহরণ (মডার্ন স্টাইল):
function greetUser(name) {
    // ব্যাকটিক (``) এর ভেতর পুরো লাইনটা লিখে ভেরিয়েবলকে ${} এর ভেতর দিতে হয়
    console.log(`হ্যালো ${name}, কেমন আছো?`);
}

greetUser("Tabib"); // আউটপুট: হ্যালো Tabib, কেমন আছো?

📂 অধ্যায়: ০৬ (পার্ট -৪)
📌 টপিক: Return Keyword (ফলাফল বাইরে পাঠানো)
========================================================================

■ What? (রিটার্ন কী?)
------------------------------------------------------------------------
`return` হলো ফাংশনের ভেতরের তৈরি হওয়া কোনো ফলাফলকে ফাংশনের দেয়াল ভেদ করে 
বাইরে পাঠিয়ে দেওয়ার একটা চাবি বা রাস্তা।

■ Why? (কেন লাগবে? React ও Node-এর বাস্তব উদাহরণ)
------------------------------------------------------------------------
১. React-এ: আমরা যখন কোনো কম্পোনেন্ট বানাই, তখন স্ক্রিনে কী ডিজাইন (HTML) 
   দেখাবে, তা এই `return` দিয়ে পাঠাতে হয়। (যেমন: return <h1>Tabib</h1>;)
২. Node.js-এ: ডাটাবেজ থেকে ইউজারের ডাটা খুঁজে এনে ফ্রন্টএন্ডে পাঠানোর জন্য 
   `return` করতে হয়।

■ গোল্ডেন রুলস (সবসময় মনে রাখবে):
------------------------------------------------------------------------
১. ফাংশন থেকে কোনো কিছু `return` করলে, বাইরে এসে সেটাকে একটা নতুন ভেরিয়েবলে 
   (যেমন: let total = addNumbers(5, 5);) রিসিভ করতে হয়।
２. `return` লেখার পর ফাংশনের ভেতরে ওর নিচে আর কোনো কোড কাজ করে না। 
   ওখানেই ফাংশনের মরণ ঘটে!

💻 লাইভ কোড স্ট্রাকচার:
------------------------------------------------------------------------
function makeJuice(fruit) {
    let juice = fruit + " এর জুস";
    return juice; // জুসটা মেশিনের বাইরে পাঠিয়ে দিল
}

let myGlass = makeJuice("আম"); // বাইরে এসে জুসটা গ্লাসে রিসিভ করলাম
console.log(myGlass); // আউটপুট: আম এর জুস
